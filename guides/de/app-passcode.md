## Authentifizierung einschalten
1. Öffne in App Lock **Einstellungen** und dann **Authentifizierung**.
2. Aktiviere **Authentifizierung**.

![Schalter für Authentifizierung](assets/crops/de/privacy-authentication-switch.png)

## Code wählen
1. Gib einen Code ein.

![Bildschirm Passcode erstellen](assets/crops/de/create-passcode-screen.png)

2. Gib ihn zur Bestätigung erneut ein.

![Bildschirm Passcode wiederholen](assets/crops/de/repeat-passcode-screen.png)

Unter **Authentifizierung** kannst du den Code ändern oder Face ID bzw. Touch ID aktivieren, falls verfügbar.
