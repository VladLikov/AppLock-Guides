Verwende Authentifizierung unter Datenschutz, wenn App Lock beim Öffnen einen Code abfragen soll.

![Datenschutz-Zeile in Einstellungen](assets/crops/de/settings-privacy-row.png)

1. Öffne App Lock.
2. Öffne **Einstellungen**.
3. Tippe im Bereich **App** auf **Datenschutz**.

![Schalter für Authentifizierung](assets/crops/de/privacy-authentication-switch.png)

4. Aktiviere **Authentifizierung**.
5. Gib auf dem Bildschirm **Passcode erstellen** einen neuen 4-stelligen Code ein.

![Bildschirm Passcode erstellen](assets/crops/de/create-passcode-screen.png)

6. Gib denselben Code auf dem Bildschirm **Passcode wiederholen** erneut ein.

![Bildschirm Passcode wiederholen](assets/crops/de/repeat-passcode-screen.png)

Tipps:

1. Lass Biometrie aktiviert, wenn du schneller entsperren möchtest.
2. Kehre später zu **Datenschutz** zurück, um den Passcode zu ändern oder die Authentifizierung zu deaktivieren.
