# Create a group

Use groups to keep apps, categories, and websites together. A group can be locked manually or by schedule.

![Home screen with Create Group](assets/home-groups.png)

1. Open App Lock.
2. Tap **Create Group** at the top of the Home screen.
3. If iOS asks for Screen Time permission, allow it. App Lock needs this permission only to block the apps you choose.
4. Select the apps, categories, or websites you want to include.
5. Tap the blue checkmark to save the group.

![App and category picker](assets/select-apps-picker.png)

Tips:

1. Use categories when you want to block a whole type of app at once.
2. Use the search field when the list is long.
3. You can edit the selected apps later from the group details screen.
