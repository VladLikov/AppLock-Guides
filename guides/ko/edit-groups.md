Home을 더 쉽게 훑어보려면 그룹 이름과 아이콘을 변경합니다.

![Home의 그룹 행](assets/crops/ko/group-row.png)

1. 그룹을 엽니다.
2. 그룹 제목 옆의 편집 버튼을 탭합니다.
3. **Rename** 을 탭해 이름을 변경합니다.
4. 새 이름을 입력하고 확인합니다.

![이름 및 아이콘 메뉴](assets/crops/ko/edit-group-menu.png)

아이콘을 변경하려면:

1. 같은 편집 메뉴를 엽니다.
2. **Choose Icon** 을 탭합니다.
3. 그룹에 가장 잘 맞는 아이콘을 선택합니다.

![Choose Icon 메뉴](assets/crops/ko/choose-icon-menu.png)

새 이름과 아이콘은 즉시 저장되어 Home과 그룹 상세 화면에 표시됩니다.
