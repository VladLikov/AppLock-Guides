## Activer l’authentification
1. Dans App Lock, ouvrez **Réglages**, puis **Authentification**.
2. Activez **Authentification**.

![Commutateur d’authentification](assets/crops/fr/privacy-authentication-switch.png)

## Choisir un code d’accès
1. Saisissez un code d’accès.

![Écran Créer un code d'accès](assets/crops/fr/create-passcode-screen.png)

2. Saisissez-le de nouveau pour le confirmer.

![Écran Répéter le code](assets/crops/fr/repeat-passcode-screen.png)

Dans **Authentification**, vous pouvez modifier le code ou activer Face ID ou Touch ID, selon leur disponibilité.
