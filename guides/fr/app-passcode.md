# Définir un code pour l’app

Utilisez Authentification dans Confidentialité si vous voulez qu’App Lock demande un code avant de s’ouvrir.

![Ligne Confidentialité dans Réglages](assets/crops/fr/settings-privacy-row.png)

1. Ouvrez App Lock.
2. Ouvrez **Réglages**.
3. Dans la section **App**, touchez **Confidentialité**.

![Commutateur d’authentification](assets/crops/fr/privacy-authentication-switch.png)

4. Activez **Authentification**.
5. Saisissez un nouveau code à 4 chiffres sur l’écran **Créer un code d'accès**.

![Écran Créer un code d'accès](assets/crops/fr/create-passcode-screen.png)

6. Saisissez à nouveau le même code sur l’écran **Répétez le code de passe**.

![Écran Répéter le code](assets/crops/fr/repeat-passcode-screen.png)

Conseils :

1. Gardez la biométrie activée si vous voulez déverrouiller plus vite.
2. Revenez dans **Confidentialité** plus tard pour modifier le code ou désactiver l’authentification.
