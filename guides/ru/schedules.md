Расписания автоматически блокируют группу в выбранные промежутки времени.

![Действие Set Schedule](assets/crops/ru/set-schedule-action.png)

1. Откройте группу, для которой нужно расписание.
2. Нажмите **MANAGE**.
3. Нажмите **Set Schedule**.
4. Включите **Use Schedule**.
5. Выберите время блокировки и разблокировки.
6. Отметьте дни, когда расписание должно работать.
7. Нажмите **Done**.

![Параметры расписания](assets/crops/ru/schedule-options.png)

Используйте **All Day**, если группа должна оставаться заблокированной весь выбранный день.

Если для разных дней нужны разные правила, создайте отдельную группу для каждого режима.
