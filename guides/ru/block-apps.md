# Блокировать приложения

После создания группы можно заблокировать все элементы группы с Home или с экрана деталей.

![Строка группы на Home](assets/crops/group-row.png)

1. Откройте группу, которую нужно заблокировать.
2. Нажмите **MANAGE** в панели навигации.
3. Нажмите **Lock All**.
4. App Lock сразу применит блокировку к выбранным приложениям, категориям и сайтам.

![Действие Lock All](assets/crops/lock-all-action.png)

Можно заблокировать и один элемент внутри группы:

1. Откройте группу.
2. Нажмите **MANAGE** рядом с приложением, категорией или сайтом.
3. Выберите действие блокировки для этого элемента.

![Меню управления элементом](assets/crops/item-lock-action.png)

Чтобы снять блокировку позже, снова откройте **MANAGE** и выберите действие разблокировки.
