# Bloquear apps

Después de crear un grupo, puedes bloquear todo el grupo desde Home o desde la pantalla de detalles.

![Fila del grupo en Home](assets/crops/group-row.png)

1. Abre el grupo que quieres bloquear.
2. Toca **MANAGE** en la barra de navegación.
3. Toca **Lock All**.
4. App Lock aplica de inmediato el bloqueo a las apps, categorías y sitios web seleccionados.

![Acción Lock All](assets/crops/lock-all-action.png)

También puedes bloquear un solo elemento dentro del grupo:

1. Abre el grupo.
2. Toca **MANAGE** junto a la app, categoría o sitio web.
3. Toca la acción de bloqueo para ese elemento.

![Menú de un elemento](assets/crops/item-lock-action.png)

Para desbloquear después, abre **MANAGE** otra vez y elige la acción de desbloqueo.
