## Activar la autenticación
1. En App Lock, abre **Ajustes** y luego **Autenticación**.
2. Activa **Autenticación**.

![Interruptor de autenticación](assets/crops/es/privacy-authentication-switch.png)

## Elegir un código
1. Introduce un código de acceso.

![Pantalla Crear código de acceso](assets/crops/es/create-passcode-screen.png)

2. Vuelve a introducirlo para confirmarlo.

![Pantalla Repetir código de acceso](assets/crops/es/repeat-passcode-screen.png)

En **Autenticación** puedes cambiar el código o activar Face ID o Touch ID si están disponibles.
