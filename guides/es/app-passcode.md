Usa Autenticación en Privacidad cuando quieras que App Lock pida un código antes de abrirse.

![Fila Privacidad en Ajustes](assets/crops/es/settings-privacy-row.png)

1. Abre App Lock.
2. Abre **Ajustes**.
3. En la sección **App**, toca **Privacidad**.

![Interruptor de autenticación](assets/crops/es/privacy-authentication-switch.png)

4. Activa **Autenticación**.
5. Ingresa un nuevo código de 4 dígitos en la pantalla **Crear código de acceso**.

![Pantalla Crear código de acceso](assets/crops/es/create-passcode-screen.png)

6. Vuelve a ingresar el mismo código en la pantalla **Repetir código de acceso**.

![Pantalla Repetir código de acceso](assets/crops/es/repeat-passcode-screen.png)

Consejos:

1. Mantén la biometría activada si quieres desbloquear más rápido.
2. Vuelve a **Privacidad** más tarde para cambiar el código o desactivar la autenticación.
